# Portal de Compras — uso gratis para tenderos

Página promocional (PWA, estilo Toyota) que invita a tenderos y emprendedores a dejar el cuaderno y usar **gratis** [Portal de Compras](https://portalcompra.netlify.app/) para registrar compras a proveedores, cartera y vencimientos desde el celular.

## Contenido
- `index.html` — la página (incluye demo interactiva de vencimientos con hora real de Colombia, America/Bogota).
- `manifest.json`, `sw.js`, `icon.svg` — archivos de la PWA (instalable y funciona sin conexión).

## Publicación
1. Crear el repo `haroldco45/portal-compras-gratis` y subir los 5 archivos.
2. Activar GitHub Pages (rama `main`, carpeta raíz).
3. Si se usa otro nombre de repo, cambiar `og:url` en `index.html`.

La imagen para redes (`og:image`) usa la de Portal de Compras: https://portalcompra.netlify.app/og-portal-compras.jpg (1200×630).

## Datos personales
La demo no guarda ningún dato. Portal de Compras guarda la información solo en el dispositivo del tendero.
